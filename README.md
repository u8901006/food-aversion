# Food Aversion Daily

食物厭惡（food aversion）跨領域研究文獻日報，每日自動從 PubMed 抓取最新文獻，由 NVIDIA AI 分析後生成網頁報告。

涵蓋領域：精神醫學、ARFID、條件化味覺嫌惡、孕吐、化療味覺改變、自閉症飲食、感官科學、營養學、公共衛生等。

## 網站

- 日報首頁: [u8901006.github.io/food-aversion](https://u8901006.github.io/food-aversion/)

## 技術

- **資料來源**: PubMed E-utilities API
- **AI 模型**: NVIDIA Nemotron 3 Super 120B A12B (fallback: NVIDIA Nemotron 3 Nano 30B A3B)
- **執行環境**: Node.js 24 + GitHub Actions
- **部署**: GitHub Pages
- **排程**: 每日 GMT+8 14:35
